// $1

Incorrectly converted length to len when a parameter (when maybe doing that expecting length to be a function)

  e.g. from utdo.pas: points[index: integer]: KfPoint3d read getPoint write setPoint;

switch missing final close brace

if there is an "exit" in a Delphi constructor (but not a regular function),
there will be a missing return in that code.
Exmaple: Uparams constructor PdParameter.make
  if fieldType = kFieldHeader then exit;

Convertign pos comparison

(varName.includes("$1"))

Superclass definition wrong -- does not use extends

Find extra parens in if statements:
  replace: \(\([^)]*\)\) \{
  with: ($1) {

Delphi case does not use break because everythign is a statement.
So, if there is a break for a loop inside a case,
it will be misinterpreted by JavaScript switch which can and usually must break in a case for the case itself.
Example: utravers procedure PdTraverser.traversePlant(traversalCount: longint); 
  if phytomerTraversing = nil then break;
Likely you will have to label the enclosing loop and use a labelled break statement; see: 
https://stackoverflow.com/questions/183161/best-way-to-break-from-nested-loops-in-javascript

Convert definitions (with this added) into streaming (example for float)
   (this\.[^:]*): float
   $1 = filer.streamSingle($1)
(Adding "this." after copying the class field definitions prevents the initial declarations from being changed.)
