This is a work-in-progress port of PlantStudio from Delphi Pascal to TypeScript for the web under the AGPL license. 

The PlantStudio application works well enough to be played with to create and breed plants. Some features not yet finished include exporting plants and editing Three-D Objects (TDOs).

You can donate to help us continue this work (donations are not tax-dedutible): https://www.paypal.com/donate?hosted_button_id=JCJS6AYH3CDN8

![PlantStudio-js main form](screenshots/PlantStudio-js%20main%20form%20Screenshot%202026-02-26%202.24.11%20PM.png)

Some historical details on the project can be found in the Readme for the earlier Delphi version: https://github.com/pdfernhout/plantstudio

This project shows how people can create a diversity of plants without "generative AI". That is done by building humanly-understandable hand-crafted models from a deep understanding of a subject and then creating user interfaces to vary and select from possible outputs of those models.
